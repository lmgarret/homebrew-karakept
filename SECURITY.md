# Security Policy

Please do **not** open a public issue for security problems.

Report problems with this tap (the cask definition or its workflows) through GitHub's
[private vulnerability reporting](https://github.com/lmgarret/homebrew-karakept/security/advisories/new).

Vulnerabilities in the Karakept app itself belong in
[lmgarret/karakept-kmp](https://github.com/lmgarret/karakept-kmp/security/advisories/new).
